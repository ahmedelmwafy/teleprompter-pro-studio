## 🌟 أبرز المميزات | Key Features

### 1. 🔊 مُملّي صوتي بشري حقيقي مجاناً 100% (Human Neural Voice Engine)
- **لا وجود للأصوات الآلية أو الروبوتية:** تم دمج محرك أصوات عصبية فائقة الواقعية (Microsoft Azure Neural) تعمل محلياً ومجاناً بالكامل دون الحاجة لأي مفاتيح API أو اشتراكات مدفوعة.
- **إملاء في سماعة الأذن للمذيع:** يمليك الجملة القادمة بصوت إنسان طبيعي ونقي فور الانتقال إليها.
- **تخزين مؤقت فوري (Zero Latency Caching):** تجهيز وسحب الصوت مسبقاً للجملة التالية لضمان تشغيل فوري بدون أي تأخير.
- **سرعة قابلة للتعديل:** تحكم كامل في سرعة القراءة (0.8x إلى 1.3x) لتناسب وتيرة إلقائك.

### 2. 📱 ريموت تحكم لاسلكي من الموبايل (Universal Controller)
- **امسح الـ QR Code:** تحكم بتقديم الجمل من شاشة هاتفك الذكي أو جهاز لوحي بضغطة واحدة دون الحاجة لتثبيت أي تطبيقات.
- **أزرار لمس عملاقة واهتزاز تفاعلي (Haptic Feedback):** مصممة خصيصاً للتحكم بإبهام اليد أثناء الوقوف أمام الكاميرا.
- **دعم ريموتات البلوتوث (Clicker):** توافق فوري وتلقائي مع أقلام الليزر وريموتات العروض التقديمية اللاسلكية (`PageUp` / `PageDown`).
- **اختصارات لوحة المفاتيح:** تقديم بـ `Space` أو `→`، ترجيع بـ `←`، إعادة من الأول بـ `R`، وتقديم زمني بـ `P`.

### 3. 🎯 التلقين الذكي جملة بجملة (Sentence-by-Sentence Reading)
- **تركيز بصري فائق (Active Focus):** عرض الجملة الحالية بالمنتصف بخط كبير ومريح، مع عرض الجملة السابقة أعلاها والجملة القادمة أسفلها بنمط باهت لتهيئة المذيع ذهنياً.
- **دعم ثنائي اللغة (Bilingual RTL/LTR):** معالجة مثالية للنصوص العربية الممزوجة بمصطلحات أو أسماء أو أرقام إنجليزية دون أي اختلال في محاذاة النص.
- **أنماط تقسيم متعددة:** تقسيم حسب الجمل الكاملة (`.` أو `!`)، أو أنصاف الجمل عند الفواصل (`،`)، أو تحديد عدد مخصص من الكلمات لكل نقلة.

### 4. 💾 حفظ نقطة التوقف تلقائياً ("وصلت لحد فين")
- يتذكر التطبيق تلقائياً رقم الجملة التي توقفت عندها في كل حلقة، لتستأنف التسجيل فوراً عند عودتك.

### 5. 🚨 تنبيه ختام الحلقة (Outro Alert)
- إشعار مرئي ينبه المذيع عند الدخول في آخر جمل السكريبت لتعديل نبرة الصوت لختام الحلقة.

### 6. 🪞 وضع المرآة للزجاج الاحترافي (Studio Mirror Mode)
- قلب أفقي فوري للشاشة (`Flip Horizontal`) متوافق مع زجاج التيليبرومبتر العاكس (Beam Splitter Glass).

### 7. ☁️ حفظ محلي ومزامنة سحابية (Local-First + Cloud Sync)
- يعمل أوفلاين 100% بدون إنترنت مع حفظ دائم على المتصفح وتصدير/استيراد نسخ JSON و TXT.
- يدعم المزامنة السحابية الفورية مع **Supabase** و **Firebase**.

## ⌨️ دليل الاختصارات وأجهزة التحكم | Controls & Shortcuts

| الزر / الأمر | الوظيفة | الأجهزة المدعومة |
| :--- | :--- | :--- |
| `مسافة (Space)` أو `السهم الأيمن (→)` | الانتقال للجملة التالية فوراً | الكيبورد |
| `السهم الأيسر (←)` | الرجوع للجملة السابقة | الكيبورد |
| `Page Down` / `Page Up` | تقديم وتأخير الجمل | ريموت البلوتوث / Presentation Clicker |
| `P` | تشغيل / إيقاف التقديم الزمني التلقائي (Timer) | الكيبورد |
| `R` | إعادة السكريبت من الجملة الأولى (Reset) | الكيبورد |
| `F` | ملء الشاشة (Fullscreen Toggle) | الكيبورد |
| `لمس الشاشة على الموبايل` | أزرار كبيرة بالهاتف مع اهتزاز تفاعلي | شاشة الموبايل عبر الـ QR Code |

## 🚀 التثبيت والتشغيل | Quick Start

### 1. المتطلبات الأساسية
- **Node.js** (إصدار 18 أو أحدث)
- **Python** (إصدار 3.9 أو أحدث)

### 2. تثبيت الاعتماديات
```bash
# تثبيت مكتبات الواجهة (React & TypeScript)
npm install

# تثبيت مكتبة محرك الصوت البشري (Python Neural Audio)
pip3 install -r requirements.txt
```

### 3. تشغيل المشروع بالكامل بضغطة زر واحدة
```bash
./start.sh
```
أو عبر npm:
```bash
npm start
```

* سيعمل التطبيق مباشرة على متصفحك عبر: `http://localhost:3000`
* وللتحكم من هاتفك الذكي: افتح الرابط الظاهر في موجه الأوامر أو امسح كود الـ QR من شريط التطبيق.

## 📁 هيكلية المشروع | Project Architecture

```
teleprompter_web/
├── index.html                   # نقطة الدخول الرئيسية مع خطوط Tajawal و Cairo
├── package.json                 # إعدادات الحزم واعتماديات الواجهة
├── requirements.txt             # اعتماديات محرك الصوت البشري (Python)
├── start.sh                     # سكربت تشغيل السيرفرين معاً بضغطة زر
├── tts_server.py                # سيرفر محرك الأصوات البشرية ومعالجة الكاش (Fast Aiohttp)
├── vite.config.ts               # إعدادات Vite والبروكسي المحلي
├── tailwind.config.js           # ألوان وثيم الاستوديو الفاتح (Light Mode)
├── src/
│   ├── main.tsx                 # تحميل React 19
│   ├── App.tsx                  # إدارة الواجهة الرئيسية والتبديل بين التلقين والمحرر
│   ├── types/
│   │   └── index.ts             # تعريفات TypeScript للحلقات والإعدادات والتحكم
│   ├── services/
│   │   ├── audioSpeechService.ts    # محرك تشغيل الصوت البشري ومتابعة الصوت
│   │   ├── controllerSyncService.ts # مزامنة الإشارات بين الهاتف والكمبيوتر فورياً
│   │   ├── storageService.ts        # التخزين المحلي والربط مع Supabase و Firebase
│   │   └── textChunker.ts           # خوارزمية تقسيم النصوص وحساب زمن القراءة
│   └── components/
│       ├── sidebar/                 # القائمة الجانبية لإدارة وأرشفة الحلقات (Light Mode)
│       ├── prompter/                # شاشة التلقين الرئيسية جملة بجملة
│       ├── editor/                  # محرر السكريبت وإشارات الإلقاء وتصدير الملفات
│       ├── controller/              # ريموت الهاتف المحمول ومولد كود الـ QR
│       ├── settings/                # نافذة اختيار الأصوات البشرية وإعدادات السحابة
│       └── common/                  # نوافذ الاختصارات والمساعدات
```
